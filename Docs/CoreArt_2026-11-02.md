## 표시 조정

- 16:9, 상하 2:1 화면과 기존 보고·자원·조작 영역을 유지했다.
- PNG 파일을 다시 그리거나 파일 자체를 자르지 않았다. Unity Sprite Editor의 사각형 범위로 보이는 부분을 지정했다. Sprite는 UI에서 사용하는 2D 그림 단위다.
- 일반 배경은 철길 주변을 가로로 잘라 표시해 1920×340 영역에서 찌그러지지 않게 했다. 전체 원본의 하늘·전경을 전부 보여주는 구도는 아니다.

- 가져오기 설정은 Sprite, Point 필터, 압축 없음, 밉맵 없음이다. 원본 해상도를 유지한다.

- Neo둥근모 Pro와 게임 규칙·기존 버튼 이벤트는 유지했다. 오른쪽 위 옛 임시 도형 안내는 ‘열국열차 프로토타입’으로 갱신했다.

## Unity에서 보는 순서

1. Project 창에서 **Assets > Scenes > PrototypeMain**을 연다.
2. **Tools > Yeolguk Train > FHD Preview**를 누른다. FHD는 1920×1080 화면 크기다.
3. 상단 Play를 켜고 타이틀의 **시작**을 누른다. 일반 구역에서 네 그림을 함께 볼 수 있다.
4. 출발 후 운행 60초가 지나 폐역으로 바뀌면 배경은 아직 단색이라는 것을 구분해 본다.

파일을 직접 확인하려면 Project의 **Assets > Art > Core**를 연다. PNG 옆 삼각형을 펼치면 표시 범위를 지정한 Sprite가 있다. 기존 연결 항목은 Hierarchy의 **MinimalRunCanvas > Inspector > Minimal Run Presentation**에 있다. 초기 세팅이나 제작 도구를 반복 실행할 필요는 없다.
